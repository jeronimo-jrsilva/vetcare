# 🐶 VetCare - Projeto Integrador (MVP Base)

Este é o esqueleto inicial para o desenvolvimento do MVP da clínica veterinária **VetCare**.

## 🚀 Como Executar Localmente
1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o aplicativo:
   ```bash
   npm start
   ```

*(Nota: Para a aula de hoje, você pode abrir os arquivos HTML diretamente no navegador ou usar uma extensão como Live Server/ferramenta de terminal como `npx live-server src` para visualizar as telas).*

---

## 🎨 Dica de Estilização: Classless CSS Frameworks
Se você quiser dar um visual profissional e moderno para o seu formulário sem precisar escrever centenas de linhas de CSS do zero, você pode importar um **Classless CSS Framework** via CDN. Eles estilizam as tags HTML padrão automaticamente!

Aqui estão algumas sugestões interessantes. Para usar, basta copiar e colar a linha `<link>` desejada dentro da tag `<head>` do seu arquivo HTML:

### 1. Simple.css (Visual limpo e corporativo)
* **Referência:** [simplecss.org](https://simplecss.org/)
* **CDN:**
  ```html
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/simpledotcss/simple.min.css">
  ```

### 2. Water.css (Moderno com suporte a tema escuro automático)
* **Referência:** [watercss.kognise.dev](https://watercss.kognise.dev/)
* **CDN:**
  ```html
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/water.css@2/out/water.css">
  ```

### 3. MVP.css (Focado em protótipos e grids rápidos)
* **Referência:** [andybrewer.github.io/mvp/](https://andybrewer.github.io/mvp/)
* **CDN:**
  ```html
  <link rel="stylesheet" href="https://unpkg.com/@andybrewer/mvp/mvp.css">
  ```

### 4. Pico.css (Muito leve e adaptável)
* **Referência:** [picocss.com](https://picocss.com/)
* **CDN:**
  ```html
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@picocss/pico@2/css/pico.min.css">
  ```
